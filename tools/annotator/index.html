OCELOT 라벨링 도구

세포 점(TC/BC)과 조직 마스크(CA/BG/UNK)를 공식 형식으로 저장합니다. 공식 정답은 열지 마세요.

1. 작업 정보

outputs/annotation_packets/<샘플ID> 폴더를 여세요.

2. 작업

조직 맥락 (빨간 상자 = 지금 보는 세포 사진)

시작 상태는 전부 BG입니다. 암 영역을 CA로, 판정이 불가능한 곳(흐림·접힘·이물질)만 UNK로 칠하세요.

3. 현황

-

판단이 어려웠던 위치

    4. 저장

    저장 폴더를 지정하지 않으면 다운로드 폴더에 <ID>.csv, <ID>.png, <ID>_notes.csv로 저장됩니다. 저장 후 python scripts/import_annotation.py --annotator <ID> --from-dir <폴더>로 가져옵니다.

    조작법

    휠: 확대/축소 · Space+드래그 또는 가운데 버튼: 이동
    세포: 클릭=점 추가(점 위 클릭=현재 클래스로 변경) · 드래그=점 이동 · 우클릭=삭제 · Q TC↔BC
    조직 다각형: 클릭으로 꼭짓점 · 더블클릭/Enter 채우기 · Backspace 마지막 점 · Esc 취소
    조직 붓: 드래그로 칠하기 · [ ] 크기
    H 라벨 숨기기 · Tab 세포/조직 전환 · Ctrl/⌘+Z 되돌리기 · Ctrl/⌘+S 저장
    분류 기준 요약 (수업 자료)
    TC: 핵이 크고 모양이 불규칙(다형성), 매우 짙은 보라(과염색), 핵/세포질 비율 큼, 둥지·샘 구조로 밀집.
    BC: 림프구(작고 둥근 짙은 핵), 섬유아세포(길쭉한 방추형), 내피세포(납작), 대식세포·정상 상피.
    CA: 종양 세포가 밀집한 암 조직 실질. BG: 정상 상피·간질·결합조직·림프·지방·혈관.
    UNK: 흐림·접힘·이물질 등 판정 불가. 작업하지 않은 곳을 UNK로 두지 않습니다.
    판단이 어려운 세포를 자동으로 BC로 정하지 말고 N 메모로 이유를 남기세요.
    작업 폴더를 열면 사진이 표시됩니다.
    (cell.jpg, tissue.jpg, metadata.json)
