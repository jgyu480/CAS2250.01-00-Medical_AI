Three temperature-gated cell ensembles. fixed uses 10 predefined context channels. learned uses 10 convolutional context channels. ae uses 9 spatial latent channels, three per receptive-field scale, pretrained at 256x256 for five epochs by default, then jointly optimized with the gate. pointwise is the 15-channel control. All use identical five-model D4 outputs. Gate logits are bounded by tanh; the effective logit amplitude divided by temperature defaults to 0.1. Weights start at exactly 0.2 and are bounded approximately to 0.170-0.234. The three models use the same fixed training duration and postprocessing grid. Selection uses val_tune, then the frozen selections are evaluated on test. Previous exposure to this test set must be disclosed in research reporting. Original base models are reused without retraining.
