# 직접 라벨링 24쌍: 공식 라벨과의 일치도 (모델 없이)

`scripts/analyze_m0.py annotators`를 만들며 확인한 결과다. 모델 성능과 무관한
라벨끼리의 비교이며, 앞쪽을 "예측"(점수 1.0), 뒤쪽을 "정답"으로 두고
공식 세포 매칭 규칙(15px)과 UNK 제외 조직 mIoU로 계산했다.

| 비교 | 세포 mF1 | 조직 mIoU |
|---|---|---|
| 공식 vs 신상우 | 0.623 | 0.835 |
| 공식 vs 이진호 | 0.296 | 0.437 |
| 이진호 vs 신상우 | 0.309 | 0.473 |

## 파일 형식 문제인지 확인

| 확인 | 이진호 | 신상우 | 해석 |
|---|---|---|---|
| 클래스 무시, 위치만 F1 | 0.676 | 0.709 | 세포 위치는 두 사람 모두 공식과 비슷하게 찍었다 |
| BC/TC를 뒤바꿔 채점 | 0.347 | 0.090 | 이진호 라벨은 바꿔도 비슷 → 전체 클래스 번호가 뒤바뀐 것은 아님 |
| x·y를 바꿔 채점 | 0.056 | 0.112 | 좌표 축 문제 아님 |
| 조직 CA·BG를 바꿔 비교 | 0.387 | 0.079 | 조직 번호가 뒤바뀐 것도 아님 |
| UNK 사용 비율 | 0% | 0% | 두 사람 모두 UNK를 쓰지 않았다 |

→ 파일 형식·좌표·번호 오류가 아니라 **판단 차이**로 보인다.

## 이진호 라벨에서 보인 경향 (이미지별)

- 조직: 공식 CA가 0%인 사진(241, 321, 325, 343, 352, 369, 399 등)에서
  이진호 라벨은 CA를 40~75% 칠했다. 공식보다 암 영역을 넓게 잡는 경향.
  (신상우 라벨은 같은 사진에서 0~3%)
- 세포: 사진에 따라 BC/TC를 뒤바꿔 채점한 쪽이 더 잘 맞는 경우가 있다
  (258, 266, 189, 380, 343, 369, 325 등). 클래스 판단이 사진마다 흔들린다.
- 세포 수: 공식 3,817개 / 이진호 3,084개 / 신상우 2,959개.
  TC 비율: 공식 58% / 이진호 70% / 신상우 54%.
